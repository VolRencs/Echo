# Echo!

## Features
- Interactive doors and objects reacting to player actions.  
- Customizable controls and UI.  
- Dynamic lighting and flashlight effects.  
- Save and load your progress.  
- Graphics settings including fullscreen, refresh rate, and VSync.  

## Controls
- **WASD** — Move  
- **Space** — Jump  
- **Shift** — Sprint  
- **Ctrl** — Crouch  
- **E** — Interact  
- **F** — Flashlight  
- **Esc** — Open menu  

## Requirements
- Godot 4.6 with **Vulkan 3.3**  
- GPU with Vulkan support  
- Windows, Linux

## Settings
- Music and sound sliders  
- VSync toggle  
- Refresh rate and fullscreen options
